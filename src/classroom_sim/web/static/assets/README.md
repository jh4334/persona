# 에셋 슬롯

기존 픽셀 원본은 이 폴더에 보존되어 있고, 앱은 `vector/`의 4배 해상도 플랫 벡터 PNG를 기본으로 사용합니다. 벡터 파일이 없으면 코드로 그린 폴백 스프라이트가 쓰입니다.

| 파일명 | 크기 | 내용 |
|---|---|---|
| `tiles.png` | 32×32 타일 | 바닥·벽·창문·소품 타일시트 |
| `blackboard.png` | 192×64 | 칠판 (좌상단 기준 x=92, y=6에 배치) |
| `desk_student.png` | 40×40 | 학생 책상+의자 세트 |
| `desk_teacher.png` | 64×48 | 교탁 |
| `char_teacher.png` | 64×48 | 교사 (32×48 × 2프레임 idle, 가로 배치) |
| `char_s01.png` ~ `char_s12.png` | 64×48 | 학생 개별 (32×48 × 2프레임 idle, 가로 배치) — 좌석 순서 = personas JSON의 students 순서 |
| `emotes.png` | 128×16 | 감정 아이콘 16×16 × 8종, 순서: 평온·들뜸·위축·불안·지루함·몰입·졸림·손듦 |

- `vector/`의 파일명과 논리 프레임 수는 위 표와 같고 실제 PNG 크기는 정확히 4배입니다.
- 타일을 제외한 `vector/` 에셋은 투명 RGBA PNG이며, 4배 오프스크린 버퍼에서 부드럽게 축소 렌더링됩니다.
- `python scripts/generate_vector_assets.py`로 18개 벡터 에셋을 재생성하고 크기·프레임·투명도를 검증할 수 있습니다.
- 프레임이 3개 이상인 캐릭터 시트를 넣으면 3번째 프레임을 "집중 낮음(엎드림)" 자세로 사용합니다.
