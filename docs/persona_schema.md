# 학생 페르소나 스키마 v2

MatrAIx의 페르소나 속성 체계(배경 / 심리 / 능력 / 행동의 4영역, 1,290개 차원)를 참고하되, MatrAIx의 세부 속성은 소비자 조사용(인구통계, 가치관, 소비 습관 등)이므로 **세부 차원은 교실 상황에 맞게 새로 설계**했습니다.

## 구조

학생 한 명은 **기본 필드**(v1과 동일)와 **5개 속성 그룹**(v2 확장, 모두 선택)으로 구성됩니다. 속성 그룹 안의 키는 자유롭게 한국어로 적으면 되고, 아래 권장 키를 쓰면 학급 간 비교가 쉬워집니다.

```
MatrAIx 4영역     →  교실용 5그룹
─────────────────────────────────────
능력 (capability) →  cognitive (인지·학습 능력), language (언어 능력)
심리 (psychology) →  motivation (동기·정서)
행동 (behavior)   →  behavior_social (행동·사회성)
배경 (background) →  environment (배경·환경)
```

## 기본 필드 (필수)

| 필드 | 설명 | 예시 |
|---|---|---|
| `id` | 학생 식별자 | `"S01"` |
| `name` | 이름 (가상) | `"김하늘"` |
| `achievement_level` | 전반적 성취 수준 | `"상"`, `"중상"`, `"중"`, `"하"` |
| `prior_knowledge` | 해당 교과의 사전 지식·결손 | 자유 서술 |
| `learning_style` | 선호 학습 방식 | 자유 서술 |
| `interests` | 흥미·관심사 목록 | `["코딩", "축구"]` |
| `personality` | 성격 | 자유 서술 |
| `social` | 교우 관계 | 자유 서술 |
| `notes` | 교사 메모 (선택) | 자유 서술 |

## 속성 그룹 (선택 — v2 확장)

### `cognitive` — 인지·학습 능력

| 권장 키 | 값 예시 |
|---|---|
| 문해력 | `"학년 수준 이상 — 긴 지문도 잘 읽음"` |
| 수리력 | `"기초 연산 느림, 자릿수 커지면 오류"` |
| 주의집중 | `"짧음 — 15분 넘으면 흐트러짐"` |
| 작업기억 | `"여러 단계 지시를 한 번에 기억하기 어려움"` |
| 처리속도 | `"정확하지만 느림 — 시간 압박에 약함"` |
| 메타인지 | `"자기가 뭘 모르는지 스스로 알아차림"` |

### `language` — 언어 능력

| 권장 키 | 값 예시 |
|---|---|
| 한국어숙달도 | `"모국어 수준"` / `"일상어 유창, 학습어휘 어려움"` |
| 어휘수준 | `"학년 평균"` |
| 표현력 | `"글보다 말로 설명할 때 정확함"` |

### `motivation` — 동기·정서

| 권장 키 | 값 예시 |
|---|---|
| 학습동기 | `"내재적 — 궁금해서 공부함"` / `"외재적 — 성적·칭찬 위주"` / `"낮음"` |
| 자기효능감 | `"낮음 — '어차피 난 못해'가 입버릇"` |
| 실패대처 | `"틀리면 금방 포기"` / `"오답을 다시 들여다봄"` |
| 시험불안 | `"평소 실력보다 시험 점수가 낮게 나옴"` |

### `behavior_social` — 행동·사회성

| 권장 키 | 값 예시 |
|---|---|
| 수업참여 | `"자발적 발표 많음"` / `"지목해야 답함"` |
| 모둠역할 | `"이끄는 역할"` / `"맡은 몫은 조용히 해냄"` |
| 도움요청 | `"모르면 바로 질문"` / `"모른다는 것을 숨김"` |
| 규칙준수 | `"수업 규칙을 잘 지킴"` |

### `environment` — 배경·환경

| 권장 키 | 값 예시 |
|---|---|
| 가정학습지원 | `"보호자가 숙제를 챙겨줌"` / `"방임에 가까움"` |
| 사교육 | `"수학 학원 주 2회"` / `"없음"` |
| 디지털접근성 | `"개인 태블릿 보유"` / `"스마트폰만 있음"` |
| 배경특이사항 | `"다문화 가정 (부모 중 한 분 외국 출신)"` |

## 작성 원칙

1. **가상 페르소나만 사용하세요.** 실제 학생의 실명·진단명·가정사를 그대로 넣지 마세요. 실제 학급을 반영하고 싶다면 "우리 반에 이런 유형의 학생이 있다" 수준으로 익명화·일반화하세요.
2. **결손과 강점을 함께 쓰세요.** "수리력 낮음"만 있는 학생보다 "수리력 낮음 + 구체물 조작에 강함"인 학생이 더 현실적인 예측과 쓸모 있는 지도 전략을 만들어냅니다.
3. **모든 그룹을 채울 필요는 없습니다.** 비어 있는 그룹은 프롬프트에서 생략됩니다. 다만 시뮬레이션 품질은 채워진 정보량에 비례합니다.
4. **값은 관찰 가능한 행동으로 쓰세요.** `"머리가 나쁨"`(낙인) 대신 `"여러 단계 지시를 한 번에 기억하기 어려움"`(관찰된 행동)처럼 쓰면 예측도 지도 전략도 구체적으로 나옵니다.
