# ChatGPT 앱으로 쓰기 (MCP)

교사가 **자기 ChatGPT 계정으로** 도트 교실 수업을 진행하는 경로입니다.
ChatGPT가 무대 감독과 학생 배우를 모두 맡고, 우리 서버는 "규칙과 기억"만
담당합니다. **서버는 LLM을 전혀 호출하지 않으므로 운영비가 0입니다.**

```
사용자의 ChatGPT (Plus/Pro)          우리 서버 (POST /mcp)
─────────────────────────           ─────────────────────────────
무대 감독 + 학생 배우          →     심판: 게이지 급변·페르소나 붕괴·발언 쏠림 교정
장면을 지어낸다                →     기억: 학급·상태·전사·리포트 보관
                                     LLM 호출 없음 = 운영비 0
```

## 기획서와 달라진 점

`docs/specs/v0.6_chatgpt_app.md`는 **버셀 + TypeScript 별도 서버**를 상정했지만,
실제로는 **기존 FastAPI 서버에 `/mcp` 엔드포인트를 하나 더했습니다.**

인증(Supabase Auth), 학급 저장소, 수업 기록, 돌발 카드, 게이지 규칙이 전부 이
서버에 이미 있어서, 따로 만들면 그대로 복제하는 셈이기 때문입니다. 배포 대상도
하나로 유지됩니다. 역할 분리(ChatGPT가 주체, 서버는 심판) 자체는 기획서 그대로고,
도구 7종도 표를 그대로 따랐습니다.

## 심판이 하는 일

이것이 커스텀 GPT와의 결정적 차이입니다. 심판이 없으면 긴 수업에서 모델은
자기가 정한 설정을 잊고, 이해도 30이던 학생을 근거 없이 90으로 만들며,
말 잘하는 학생에게만 계속 발언 기회를 줍니다.

매 `record_turn` 마다 검사해 `corrections` 배열로 돌려줍니다.

| 검사 | 처리 |
|---|---|
| 게이지가 한 턴에 25점 넘게 변함 | **값을 잘라** 25점으로 맞추고 알림 |
| 0~100 범위 밖, 형이 틀린 값 | 범위로 자르거나 이전 값 유지 |
| 학급에 없는 학생 | 무시하고 알림 |
| 수업 시간이 되돌아감 | 이전 값 유지 |
| 한 턴에 15분 초과 (시간 건너뛰기는 40분) | 상한으로 자름 |
| 국면이 목록 밖 | 이전 국면 유지 |
| 주의집중 짧은 학생이 오래 지나도 고집중 | **말로 지적** (값은 안 건드림) |
| 성취 '하'인 학생의 이해도가 근거 없이 급등 | 말로 지적 |
| 최근 12턴 발언의 40% 초과가 한 학생에게 | 말로 지적 |
| 한 번도 드러나지 않은 학생 | 이름을 알려 줌 |

값을 자르는 것(hard)과 말로 짚는 것(soft)을 나눈 이유: 수치가 범위를 벗어난 것은
버그지만, 개연성 문제는 맥락에 따라 정당할 수 있어서 판단을 모델에게 남깁니다.

## 도구 7종

| 도구 | 하는 일 |
|---|---|
| `list_classrooms` | 학급 목록 |
| `create_classroom` | 학급 JSON 검증 후 저장 |
| `start_session` | 전체 페르소나 + 초기 게이지 + **연기 지침** |
| `record_turn` | 연기 결과 보고 → 검사 → **교정 지시** |
| `get_state` | 게이지 표 (교사 전용) |
| `trigger_incident` | 돌발 카드 (중복 없이) |
| `end_session` | 1차: 통계 + 리포트 틀 / 2차: 완성 리포트 저장 |

`end_session`이 두 번 호출되는 이유: 통계는 서버가 세야 믿을 수 있고(발언 분포,
소외 학생), 리포트 문장은 모델이 써야 읽을 만하기 때문입니다.

## 연결하기

### 1. 서버를 인터넷에서 접근 가능하게

ChatGPT가 서버를 호출해야 하므로 공개 주소가 필요합니다.

```bash
# 로그인을 반드시 켜세요 (docs/supabase_setup.md 2단계)
export SUPABASE_URL=https://obmlsijdaknzwktplklr.supabase.co
export SUPABASE_ANON_KEY=<anon 키>
export SUPABASE_JWT_SECRET=<JWT Secret>

PYTHONPATH=src python -m classroom_sim.web --host 0.0.0.0 --port 8000
```

터널로 임시 공개하려면:

```bash
cloudflared tunnel --url http://localhost:8000
# 또는  ngrok http 8000
```

> ⚠️ **인증 없이 공개하지 마세요.** `curl <주소>/healthz` 가
> `"auth":"required"` 인지 먼저 확인합니다.

### 2. 연결 확인

```bash
curl -s https://<주소>/mcp        # 도구 목록·프로토콜 버전이 나옵니다
```

### 3. ChatGPT에 등록

ChatGPT → 설정 → **커넥터 / 개발자 모드** → MCP 서버 추가

- **URL**: `https://<주소>/mcp`
- **인증**: Bearer 토큰. 웹 화면에 로그인한 뒤 브라우저 콘솔에서
  `JSON.parse(localStorage.cs_auth).access_token` 으로 꺼냅니다.

> 토큰은 만료됩니다(기본 1시간). 장시간 쓰려면 Supabase의 JWT 만료 시간을
> 늘리거나, 만료될 때마다 다시 등록해야 합니다. 이 부분은 아직 거칩니다.

### 4. 수업하기

ChatGPT에게 이렇게 시작하면 됩니다.

```
교실 무대 도구로 수업을 시작해 줘. 6학년 3반, 비와 비율 단원이야.
내가 교사 역할이고, 내가 말하는 걸 record_turn으로 보고해 줘.
```

이후에는 그냥 수업하듯 말하면 됩니다. ChatGPT가 학생들을 연기하고, 매 턴
서버의 교정 지시를 받아 반영합니다. 끝나면 "수업 마치자"라고 하면 리포트를
써서 저장하고, **웹 화면의 [지난 수업 기록]에서도 볼 수 있습니다.**

## 알려진 한계

- **토큰 만료.** 위에 적은 대로 OAuth가 아니라 수동 Bearer 토큰입니다.
  제대로 하려면 MCP OAuth 흐름을 붙여야 합니다.
- **도트 교실 화면이 없습니다.** 기획서의 Apps SDK 컴포넌트(iframe으로 캔버스
  렌더러 이식)는 아직입니다. 지금은 `get_state`의 표로만 상태를 봅니다.
  수업 후 웹 화면에서 기록을 열면 리포트는 볼 수 있습니다.
- **연기 품질은 모델에 달렸습니다.** 심판이 명백한 이탈은 잡지만, "그럴듯하지만
  밋밋한" 연기까지 막지는 못합니다.
- 서버가 켜져 있어야 합니다. 터널을 쓰면 주소가 바뀔 때마다 다시 등록해야 합니다.
