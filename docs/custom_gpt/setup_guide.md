# 커스텀 GPT "교실 무대" 제작 가이드 (5분)

심사 없이 링크 공유로 배포되는 선발대 버전입니다. 만드는 데 5분이면 됩니다.

## 만들기

1. ChatGPT → 좌측 **GPT 탐색** → 우측 상단 **만들기(Create)** → **구성(Configure)** 탭
2. 각 칸을 채웁니다:

| 칸 | 값 |
|---|---|
| 이름 | `교실 무대 — 수업 시뮬레이터` |
| 설명 | `가상 학생 페르소나 12명이 있는 교실에서 실제처럼 수업을 진행해 보는 시뮬레이터. 교사 연수·수업 설계 리허설용.` |
| 지침(Instructions) | **[instructions.md](instructions.md)의 구분선 사이 전문을 붙여넣기** |
| 대화 시작어 | 아래 4개 |
| 지식(Knowledge) | 이 저장소의 `personas/class_6_3.json`, `lessons/ratio_and_rate.md` 업로드 |
| 기능 | **웹 검색 끄기, 이미지 생성 끄기, 코드 인터프리터 끄기** (지식 파일 유출 방지 겸 불필요) |

대화 시작어 4개:
- `수업 시작할게요. 학급 명단부터 보여주세요.`
- `우리 반 학급 파일을 올릴게요. 이걸로 진행해 주세요.`
- `/상태`
- `/돌발`

3. 우측 상단 **만들기 → 공유 대상: 링크가 있는 모든 사람** → 링크 복사

## 사용 안내 (동료 교사에게 같이 전달)

- ChatGPT 유료 구독(Plus 이상)이면 링크 클릭만으로 사용 가능, 별도 설치·비용 없음
- 기본 학급(가상 6학년 12명)으로 바로 시작하거나, 자기 학급 JSON(작성법: [docs/persona_schema.md](../persona_schema.md))과 수업안을 채팅에 올려서 진행
- 명령: 그냥 말하면 전체 발화, `@이름`으로 지목, `/판서 /활동 /모둠 /순회 /돌발 /상태 /종료`
- **실제 학생의 실명·민감정보를 올리지 마세요** (가상 이름·일반화된 특성만)

## 한계 (본편과의 차이)

- 도트 교실 화면 없음 (텍스트 연출)
- 게이지 추적이 모델 기억에 의존 — 긴 수업에서는 `/상태`로 주기적으로 고정하는 것을 권장
- 수업 기록이 대화 밖에 저장되지 않음 (리포트를 복사해 보관)

이 한계들이 아쉬워지면 그때가 v0.6(ChatGPT 앱 — 도트 교실 + 저장 기능)으로 넘어갈 시점입니다.
