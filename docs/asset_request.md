# 도트 교실 에셋 요청서 (Codex 발주용)

"보이는 교실" 웹 화면에 쓸 픽셀아트 에셋 목록과, Codex에 그대로 붙여넣을 수 있는 요청 프롬프트 모음입니다.

- **적용 방법**: 완성된 PNG를 `src/classroom_sim/web/static/assets/`에 아래 파일명 그대로 넣으면 자동 적용됩니다 (파일이 없으면 코드가 그린 임시 스프라이트로 표시됨).
- **공통 규격**: PNG, 투명 배경(타일 제외), 알파 채널 유지. 안티앨리어싱 금지(순수 픽셀). 업스케일 금지 — 원본 픽셀 크기 그대로 저장.

## 공통 스타일 가이드 (모든 요청에 함께 전달)

> 게더타운(Gather Town)·Sprout Lands풍의 따뜻한 16비트 픽셀아트. 초등학교 교실. 밝고 아기자기한 색감, 두꺼운 외곽선 없음, 부드러운 명암 2단계. 팔레트는 32색 이내로 통일: 나무 바닥(#C8996B 계열), 크림색 벽(#F2E8D5 계열), 초록 칠판(#3E6B4F 계열), 포인트 색은 채도 중간의 파스텔. 위에서 비스듬히 내려다보는 탑다운 3/4 시점.

## Codex 요청 프롬프트 (복사해서 사용)

> **코덱스 사용 팁**: 코덱스는 이미지 생성 AI가 아니라 코딩 에이전트이므로, 아래 프롬프트 앞에 다음 문장을 붙여 **"코드로 그리게"** 시키는 것을 권장합니다. 결과물의 크기·투명배경·팔레트가 규격대로 정확히 나옵니다.
>
> ```
> 아래 규격의 픽셀아트 PNG를 Python(Pillow) 스크립트로 픽셀 단위로 그려서 생성해줘.
> 스크립트를 작성·실행해 정확한 크기의 PNG 파일로 저장하고, 규격(크기·투명배경·팔레트)을
> 코드로 검증까지 해줘. 이 저장소의 docs/asset_request.md 규격을 따르고, 완성 파일은
> src/classroom_sim/web/static/assets/ 에 저장해줘.
> ```
>
> 코덱스 로그인은 ChatGPT 계정(Sign in with ChatGPT)으로 하면 되고, 구독 한도 내에서 추가 비용이 없습니다.

### ① 마스터 프롬프트 (첫 요청 시 스타일 고정용)

```
초등학교 교실 시뮬레이션 게임의 픽셀아트 에셋 세트를 만들어줘.
스타일: 게더타운(Gather Town)·Sprout Lands풍 따뜻한 16비트 픽셀아트, 탑다운 3/4 시점,
안티앨리어싱 없는 순수 픽셀, 부드러운 명암 2단계, 32색 이내 통일 팔레트
(나무 바닥 #C8996B, 크림 벽 #F2E8D5, 초록 칠판 #3E6B4F, 파스텔 포인트).
투명 배경 PNG, 원본 픽셀 크기 그대로(업스케일 금지).
이 스타일을 기준으로 이후 요청하는 모든 에셋을 같은 팔레트·시점으로 만들어줘.
```

### ② 타일시트

```
32×32 픽셀 타일 8종을 가로로 이어붙인 시트(256×32) tiles.png:
1) 나무 바닥 2) 나무 바닥 변형(옹이) 3) 크림색 벽 4) 창문(파란 하늘·구름)
5) 게시판(그림 붙은) 6) 초록 사물함 7) 화분 8) 교실 문.
타일끼리 이어붙여도 무늬가 자연스럽게 반복되어야 함.
```
