# 첫 실전 리허설 가이드 — 코덱스 백엔드로 AI 수업 돌리기

mock(규칙 기반)이 아닌 **실제 AI가 학생을 연기하는 첫 수업**을 돌리는 절차입니다. ChatGPT 구독(코덱스)으로 실행하므로 API 결제가 필요 없습니다.

## 1. 준비 (1회만)

```bash
# Node 18+ 필요
npm install -g @openai/codex
codex login          # 브라우저에서 ChatGPT 계정 로그인
codex exec "안녕이라고만 답해줘"   # 비대화형 모드 동작 확인
```

```bash
git clone https://github.com/jh4334/persona -b claude/student-persona-learning-test-9nzrkz
cd persona
pip install -r requirements.txt
```

## 2. 실행

```bash
# 터미널판 (리허설에 권장 — 로그가 그대로 보임)
PYTHONPATH=src python -m classroom_sim.stage \
    --personas personas/class_6_3.json \
    --lesson lessons/ratio_and_rate.md \
    --backend codex

# 웹판 (도트 교실)
PYTHONPATH=src python -m classroom_sim.web --port 8000
# 브라우저에서 http://localhost:8000 → 백엔드 "codex" 선택
```

옵션: `--codex-bin /경로/codex`(PATH에 없을 때), `--codex-model 모델명`, `--codex-timeout 600`(느릴 때).

## 3. 권장 첫 시나리오 (10턴 대본)

속도 체감을 위해 첫 판은 아래 대본을 그대로 순서대로 입력해 보세요. 턴당 수십 초 걸리는 것이 정상입니다.

```
1. 오늘은 '비'에 대해 배워볼 거예요. 우리 반 남학생 12명, 여학생 13명을 비교하는 방법이 뭐가 있을까요?
2. @김하늘 하늘이는 어떻게 비교하면 좋을 것 같아?
3. /판서 뺄셈 비교: 13-12=1  /  나눗셈 비교: 12÷13
4. 두 수를 나눗셈으로 비교하기 위해 기호 :을 사용한 것을 '비'라고 해요. 12 대 13이라고 읽어요.
5. @최민준 민준아, 3 대 5에서 앞의 수가 뭐라고 했지?
6. /순회 최민준 색깔 막대로 같이 만들어볼까?
7. @한시우 시우야, 축구 슛 5번 중 3번 성공하면 비로 어떻게 나타낼까?
8. /활동 짝과 함께 교실에서 비로 나타낼 수 있는 상황을 3가지 찾아보세요
9. /시간 5분
10. /종료
```

## 4. 관찰 포인트 (이걸 봐주세요)

리허설의 목적은 **프롬프트 튜닝 재료 수집**입니다. 아래 항목을 확인하고 어긋난 장면을 기록해 주세요.

| 항목 | 기대 | 어긋남 예 |
|---|---|---|
| 페르소나 일관성 | 최민준은 위축, 김하늘은 자신감, 한시우는 어휘 막힘 | 최민준이 갑자기 유창하게 정답 설명 |
| 오개념 재현 | 3:5와 5:3 혼동 같은 틀린 답이 **틀리게** 나옴 | 모든 학생이 정답만 말함 (미화) |
| 게이지 움직임 | 설명이 길어지면 강도윤 집중부터 하락 | 12명이 똑같이 움직임 |
| 침묵의 표현 | 위축된 학생은 "……(고개를 숙인다)" 같은 행동 | 지목마다 전원이 또박또박 대답 |
| 말투 | 초등 6학년다운 짧은 구어 | 어른스러운 설명조 |
| JSON 오류 | 없어야 정상 (1회 자동 재시도 있음) | "감독 호출 실패" 메시지 반복 |
| 속도 | 턴당 30초~2분 | 5분 이상 걸리는 턴 다수 |

## 5. 문제 발생 시

| 증상 | 대처 |
|---|---|
| `codex CLI를 찾을 수 없습니다` | 설치 확인, 또는 `--codex-bin` 으로 경로 지정 |
| `codex login 상태와 구독 한도를 확인하세요` | `codex login` 재실행. 반복되면 구독 사용 한도 초과 — 잠시 후 재시도 |
| 타임아웃 | `--codex-timeout 600` |
| 감독 호출 실패가 잦음 | 발생한 턴의 입력을 기록해서 공유 (프롬프트 보강 재료) |

## 6. 리허설 후 공유해 주면 좋은 것

`reports/`에 저장된 **사후 리포트(.md)와 전사(_transcript.json)** 두 파일이면 충분합니다. 그걸 바탕으로 감독·학생 프롬프트를 코덱스 특성에 맞게 조정합니다 (특히 "관찰 포인트"에서 어긋난 장면).
